# ちゃっと物資管理 1.0.0

避難所や地域行事で、物資の品目・概数・保管場所・不足状況をスタッフで共有するDelta Chat用アプリです。インターネットがない場合の利用を想定し、TinyBoxなどのローカル通信環境で使えます。

数量が分からないときも、空欄と「十分・少ない・不足・不明」で記録できます。数字を埋めるために0を入れる必要はありません。

## アプリと操作マニュアル

- [アプリ 1.0.0を使う](chatto-busshi-1.0.0.xdc)
- [画面図表入り操作マニュアル HTML版](chatto-busshi.html)
- [ブラウザで試す](chatto-cusshi-demo.html)

マニュアルは全18ページ・図22点です。HTML版は図を含む1ファイルなので、保存後もオフラインで読めます。画面例は架空の練習用データを使った1.0.0のブラウザ表示です。iPhone・Android・パソコンでは配置やファイル選択画面が異なる場合があります。

## 最初にすること

1. 管理担当者にTinyBoxのWi-FiとDelta Chatのアカウントを準備してもらい、別端末へ普通のチャットが届くか確認します。
2. 避難所・行事ごとの職員用グループへ `.xdc` ファイルを1回添付します。
3. 全員が**同じ添付メッセージ**のアプリを開きます。各自が送り直すと別の台帳になります。
4. 「入庫・登録」から品目名・保管場所・単位を登録し、数量または状況、記録者を入力します。
5. 受け取ったら「入庫」、渡したら「配布・使用」を記録します。現物と違ったら「棚卸し・状況確認」を使います。

操作の練習は、運用中の台帳と分けた練習用の添付で行ってください。

## できること

- 品目・保管場所・単位・カテゴリ・概数を管理する。
- 数量が不明でも、4段階の状況だけで記録する。
- 入庫・配布・使用・棚卸し・訂正を履歴として残す。
- 品目と場所の検索、カテゴリ・状況の絞り込み、不足目安や期限のアラートを使う。
- 複数担当者の更新を共有し、競合や数量不明を要確認として表示する。
- ちゃっと入退場1.6.0のJSONから人数・配布実績を取り込み、確認後に在庫へ反映する。
- JSONで記録、CSVで現在の一覧を書き出す。
- 端末ごとに15言語を選ぶ。アラビア語の右から左表示と明暗モードに対応する。

## 5つのタブ

|タブ|すること|
|---|---|
|在庫|物資の場所・概数・状況を確認する|
|入庫・登録|新規登録、入庫、棚卸し、管理情報の訂正|
|配布・使用|渡した数量・使った数量と、必要なら配布先の班や場所を記録する|
|履歴|誰が何を記録したか確認する|
|設定|入退場連携、JSON・CSV出力、未受理分の再送|

## 間違えやすい入力

- 入庫・配布では**今回の増減量**を入れます。100本から30本入庫なら入力は30です。
- 棚卸しでは**現在の総数**を入れます。表示110本、現物108本なら入力は108です。
- 空欄は数量不明、0は確認した結果の0です。
- 「十分・少ない・不足・不明」は現場の判断です。不足目安による警告と独立しています。
- 単位を変えても自動換算しません。新しい単位で棚卸しを記録します。

## 通信が遅いとき

記録はまず端末へ保存します。共有にはTinyBoxのWi-Fiとローカルメールなどの経路が必要です。接続を確認し、必要なら設定画面で未受理分を再送します。

「未受理0件」は全員への配達・既読を保証しません。担当者同士で一覧と履歴を確認してください。同じ入出庫を新しく手入力して再送の代わりにすると、二重計上になります。

## 入退場の人数と配布実績を使う

1. ちゃっと入退場でJSONバックアップを書き出します。
2. 物資管理の設定画面で、元の添付台帳ごとに固定した同じ「連携台帳ID」を全担当者が使って取り込みます。
3. 人数と配布実績を確認します。**取り込むだけでは在庫は減りません。**
4. 在庫へ反映する場合だけ、対応する品目・保管場所・単位・開始日時を確認し、確認チェックを付けて反映します。

再取込や同時反映では同じ元配布記録を1回だけ差し引きます。ただし、別の連携台帳IDを付けた同じデータや、手入力との意味上の重複は自動では除去できません。棚卸し済み・手入力済みの配布を再び引かないようにします。

元JSONには個人情報があります。職員用の範囲で扱ってください。物資管理へ保存・共有するのは、人数集計と配布実績だけで、元の氏名・住所・電話・人物IDは含めません。

## 表示言語

日本語、英語、中国語 簡体字、韓国語、ベトナム語、タガログ語、フィリピン語、ポルトガル語、ネパール語、スペイン語、フランス語、ドイツ語、アラビア語、インドネシア語、ロシア語に対応します。

画面上部の「表示言語 / Language」で選びます。設定はその端末だけに保存します。入力済みの品目名・保管場所・単位・メモは翻訳しません。

## 保管とできないこと

数量は概数で、配布予約や残数の確約には使えません。個人別の配給資格・本人認証・コピーQR防止を判断するアプリでもありません。品目やメモに個人情報を書かない運用にしてください。

物資管理JSONを読み込んで台帳を復元する機能はありません。入退場JSONの取込とは別です。元の添付メッセージも保管してください。旧版や別添付の台帳を自動移行・統合する機能はありません。切替時は旧台帳を残し、記録の保管と現物の棚卸しを行います。

入退場JSON取込は10MB・元履歴2万件までです。端末の空き容量により、それより少なくても保存できない場合があります。

運用前に2台で登録・入庫・配布・再接続・再送・出力を試し、担当者間で入力ルールをそろえてください。
